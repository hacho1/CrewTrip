# 검증 기록

## 2026-11-07 공개 release

공개 제출 폴더에서 `npm ci` 후 웹 빌드와 서버 테스트 13/13이 통과했다. `emulatorRelease` 컴파일·패키징과 단위 테스트 4/4가 통과했으며, 전용 인증서로 서명하고 디버깅 해제 상태와 APK 서명을 확인했다. GitHub의 APK를 로그인 없이 다시 내려받아 로컬 파일과 SHA-256이 일치하는 것도 확인했다.

읽기 전용으로 부팅한 Pleos 에뮬레이터에 새 release를 설치했고, 설치된 APK의 해시와 제출 파일의 일치, 실제 P 상태에서 로컬 서버의 첫 화면이 표시되는 것까지 확인했다. [release 기동 화면](media/release-P-entry.png)

이후 자동화 도구가 입력 요소의 위치를 찾지 못해 이 release의 여행방 생성과 D/P 전환 검증은 완료하지 못했다. 앞선 실행에는 설치 대기 시간 초과와 Virtual Console 준비 오류도 있었다. 아래의 이전 브라우저 회귀와 실제 외부 연결 결과는 각각의 날짜와 범위를 따른다. [검증 메타데이터](verification.json)


브라우저 회귀에는 모의 ITS·합성 HLS 영상·위치·D/P 상태를 사용하는 테스트가 포함됩니다. 실제 교통 상황과 기능 회귀를 구분해 기록합니다.

## 알려진 제약

- 현 에뮬레이터·NaviHelper 조합에서 일부 경유지 조회가 좌표를 반환하지 않았습니다. 요청 좌표와 대조할 수 없으면 반영 미확인을 유지하고 재추가를 보류합니다.
- TPMS 경고 조회는 현재 권한으로 제한됩니다. 실제 타이어 저압 경고 기능을 제공한다고 표시하지 않습니다.
- 실제 휴대폰 2대에서 원래 QR로 참가하는 전체 흐름과 실차 실행은 추가 검증 대상입니다.
- 방과 기록은 서버 메모리에 보관하며 서버 재시작 후 복원되지 않습니다.
- 웹 빌드에 HLS 청크 크기 경고와 차량 SDK의 기존 기어 API 사용 중단 예정 경고가 남아 있습니다.

제출 release의 빌드·서명 및 실행 확인은 공개본의 `verification.json`에 기록합니다.
